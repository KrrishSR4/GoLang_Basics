## Go Commands

### Development

```bash
go run
go build
go install
go fmt
go generate
```

### Testing and Code Quality

```bash
go test
go vet
go fix
```

### Modules and Dependencies

```bash
go mod
go get
go list
go work
```

### Environment and Documentation

```bash
go env
go version
go doc
go help
```

### Project and Build Management

```bash
go clean
go tool
```

### Other Commands

```bash
go bug
go telemetry
```

For detailed information about any command:

```bash
go help <command>
```

Example:

```bash
go help build
go help mod
go help test
```
